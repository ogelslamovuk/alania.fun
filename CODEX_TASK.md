# Редизайн alania.fun

## Цель

Привлекать обращения туристов в WhatsApp Эльбруса. Он родился и вырос в Верхнем Фиагдоне, знает горы, культуру и историю Осетии, внимательно и вежливо общается. Сайт должен передавать его характер и помогать договориться о поездке.

## Решения из разговора 16 ноября 2026 года

- Все туристы, без отдельного сегмента по составу компании.
- Полная свобода нового визуального направления. Ориентир качества — современная авторская туристическая страница.
- Любой маршрут обсуждается с Эльбрусом. Основная кнопка WhatsApp, Telegram и звонок также доступны.
- Машина и сопровождение входят в согласованную цену. Еда, билеты и канатки оплачиваются отдельно.
- Обязательной предоплаты нет. Платёжная система относится к будущей работе.
- При плохой погоде маршрут меняют или поездку переносят по договорённости.
- Отзывы сохраняются дословно в текущем виде. Вымышленные эпизоды и истории от лица Эльбруса не добавляются.
- Рыночные диапазоны стоимости допустимы как приблизительные ориентиры. Точный тариф согласуется лично.
- Два MOV пользователя остаются локальными оригиналами. Для сайта используется сжатый фрагмент с постером.

## Реализация

Существующие React 19, Vite 8, TypeScript, GitHub Pages, base `./`, master. Одна страница. Сохраняются серверная генерация HTML при сборке, гидратация, SEO verification-файлы и Метрика. Локальный Node 22.23.5 и npm 10.9.9 из D:/soft/node-v22.23.5. Временные файлы на D:, после проверки серверы останавливаются.

## Обязательная приёмка

1. Полностью оформленная страница с русской типографикой, оригинальной композицией, настоящими фотографиями и понятным предложением.
2. WhatsApp доступен на первом экране и далее по странице, Telegram и телефон доступны. Маршрутные CTA готовят осмысленный текст сообщения.
3. Все разделы, якоря, навигация, видео, FAQ и форма работают на 360/390/768/1440 px без горизонтального скролла и перекрытия кнопок.
4. Форма сохраняет проверенный контракт HTTP 2xx + JSON ok=true, тайм-аут, защиту повторного запроса и поля после ошибки. Без endpoint открывается черновик WhatsApp без ложного подтверждения отправки.
5. Существующие отзывы сохраняются дословно. Нет вымышленных точных цен, рейтингов, сертификатов, услуг или историй.
6. Основной контент, FAQ и контакты доступны без JavaScript. JSON-LD соответствует видимому тексту, canonical и sitemap указывают на https://alania.fun/.
7. Полезный заголовок, description, Open Graph, доступный HTML, локальные шрифты с кириллицей, оптимизированные фото и видео с preload=none. Видео не задерживает первый экран.
8. npm run build проходит. Независимый QA с оценкой минимум 8/10 проверяет браузерные сценарии, мобильный рендер, форму с перехватом, отсутствие новых P0/P1 и настоящий PR diff.
9. После ревью — merge, GitHub Pages deployment, независимый E2E и live smoke на точном опубликованном SHA. Реальные сообщения и звонки не выполняются.
10. README и кредиты медиа актуальны. Секреты, MOV-оригиналы, зависимости и временные доказательства не публикуются в Git.

## Границы

Без нового backend, платежей, CMS, тяжёлых библиотек, миграции хостинга и изменений DNS. Существующий публичный репозиторий и домен остаются площадкой согласованной работы. Визуальный контракт и ссылки на источники записываются в DESIGN.md. При провале QA исправляется конкретный дефект и повторяется связанная проверка.
